# Champions League Chatbot Backend

This backend powers a hybrid UEFA Champions League chatbot. The system answers historical Champions League questions using both structured SQL queries and FAISS-based semantic retrieval.

## Project Overview

The chatbot uses a hybrid architecture:

* SQLite database for structured statistical questions
* FAISS vector database for semantic retrieval questions
* Rule-based query router for selecting SQL, RAG, or hybrid route
* FastAPI backend API for frontend communication

This design is used because pure vector retrieval is not reliable for ranking, counting, filtering, and aggregation questions. For example, questions like “Who is the 5th highest goalscorer?” or “How many players scored more than 100 goals?” are answered through SQLite. More descriptive questions like “Tell me about Roy Makaay’s fastest goal” are answered through FAISS retrieval.

## Setup

Create and activate a virtual environment:

```bash
python -m venv venv
```

For Windows PowerShell:

```bash
.\venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Validate Data

Inspect the SQLite database:

```bash
python scripts/inspect_sqlite_db.py
```

Validate the RAG corpus:

```bash
python scripts/validate_rag_corpus.py
```

## Build FAISS Index

Create the FAISS vector index from the RAG corpus:

```bash
python scripts/build_faiss_index.py
```

This creates:

```text
rag_index/index.faiss
rag_index/documents.pkl
rag_index/metadata.pkl
```

## Run Backend

Start the FastAPI server:

```bash
python -m uvicorn app.main:app --reload
```

Open Swagger UI:

```text
http://127.0.0.1:8000/docs
```

Health check:

```text
http://127.0.0.1:8000/api/health
```

## Chat Endpoint

Endpoint:

```http
POST /api/chat
```

Example request:

```json
{
  "message": "Who is the 5th highest goalscorer?"
}
```

Example response:

```json
{
  "route": "sql",
  "answer": "The requested ranked goalscorer is Raúl González, with 71 goals for Spain.",
  "sql_intent": "nth_top_goalscorer",
  "sql_result": [
    {
      "Player": "Raúl González",
      "Goals": 71,
      "Nationality": "Spain"
    }
  ],
  "retrieved_docs": null,
  "sources": null
}
```

## CLI Chat Test

A simple terminal chatbot can be used before frontend integration:


## Supported Question Types

SQL route examples:

* Who is the 5th highest goalscorer?
* Who has the most Champions League goals?
* How many players scored more than 100 goals?
* How many goals did Messi score?
* Which club has the most titles?
* How many titles does Real Madrid have?
* Who was the top scorer in 2014/15?

RAG route examples:

* Tell me about Roy Makaay’s fastest goal.
* Who scored after 10.12 seconds?
* Give me details about the fastest Champions League goal.

Hybrid route examples:

* List the top 3 goalscorers and explain their records.

## Current Limitations

* The SQL intent detector is rule-based and may not understand all possible phrasings.
* The system currently formats answers manually instead of using a local LLM generation step.
* User authentication and chat history are not implemented yet.
* Source display is planned but currently optional in the API response.
* Cross-encoder reranking and LLM-based Text-to-SQL can be added in later stages.
